Test links

Tap a link, then tap Open when Safari asks to open it in Brief. Try each one twice: once with Brief closed (swipe it away first) and once with Brief open in the background.

  • Settings: Brief opens on Settings.
  • A challenge that doesn’t exist: Brief opens a challenge screen that says “That code didn’t work”.
  • A squad invite: Brief opens Join a squad with the code BCDFG-23456 filled in. (No squad has that code, so joining it will say so.)
  • Brief itself: Brief opens on Today.

To test a real challenge, start one in Brief, note its code, and type brief://challenge/ followed by the code into Safari’s address bar.
